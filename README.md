# 基于Python的IT岗位招聘数据可视化分析系统

基于 Flask + SQLite + ECharts 构建的 IT 岗位招聘数据可视化分析平台。系统对招聘数据进行清洗与标准化，通过多维度可视化图表展现 IT 行业薪资水平、岗位需求、城市分布与企业画像，并集成了基于机器学习的岗位推荐与薪资预测功能。

## 功能特性

### 用户端
- **数据总览仪表盘**：岗位总数、企业数量、覆盖城市、平均薪资等核心指标与趋势图
- **数据浏览**：分页浏览岗位详情，支持按城市、岗位类型、学历、经验等多条件筛选
- **岗位收藏**：收藏感兴趣的岗位，查看个人收藏列表与收藏统计
- **智能岗位推荐**：基于 TF-IDF + 余弦相似度，根据用户条件推荐匹配岗位
- **薪资预测**：基于随机森林回归模型，输入岗位、城市、学历、经验等信息预测薪资区间
- **薪资分析**：薪资分布直方图、学历-薪资、经验-薪资箱线图与折线图
- **城市分析**：城市薪资排行、岗位分布地图（热力图）、城市薪资趋势、城市对比雷达图
- **岗位分析**：热门岗位排行、岗位类型统计、技能词云
- **企业分析**：企业类型、企业规模、企业性质分布，招聘数量 Top 企业
- **对比分析**：企业对比、城市对比、岗位类型对比多维度雷达图
- **职业建议**：根据学历、经验与目标岗位类型，匹配真实岗位数据给出就业建议
- **个人中心**：修改昵称、密码等个人资料

### 管理端
- **数据管理**：岗位数据的增删改查
- **CSV 数据导入**：支持上传 CSV 文件批量导入招聘数据，自动完成字段清洗与标准化
- **用户管理**：用户列表查看、编辑、删除与批量删除
- **日志管理**：记录并查看系统操作日志（登录、增删改、导入等）
- **系统管理**：管理员修改密码等系统设置

### 数据处理与算法
- **薪资解析**：支持「K/月、K/年、万/月、万/年」等多种格式，统一换算为月薪区间
- **岗位归一化**：岗位名称分类与标准化（开发、测试、运维、数据、算法、网络安全、项目产品等）
- **企业识别**：根据公司名称关键词识别企业类型与企业性质
- **文本情感分析**：对招聘文案进行情感倾向分析
- **机器学习**：scikit-learn 实现 TF-IDF 文本向量化推荐与随机森林薪资回归预测

## 项目结构

```
├── app.py                  # Flask 主程序（模型、数据处理、算法、API、路由）
├── jobs.csv                # 原始招聘数据（首次启动自动导入）
├── jobs.db                 # SQLite 数据库（运行时自动生成）
├── requirements.txt        # Python 依赖
├── templates/              # 页面模板
│   ├── base.html           # 布局母版
│   ├── login.html          # 登录页
│   ├── register.html       # 注册页
│   ├── user/               # 用户端页面（仪表盘、分析、推荐、预测等）
│   └── admin/              # 管理端页面（数据管理、导入、日志、系统管理）
└── static/                 # 静态资源（js / css / fonts）
```

## 快速开始

### 环境要求
- Python 3.11+

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动系统

```bash
python app.py
```

启动后系统会自动完成以下初始化：
1. 创建数据库表与默认管理员账号
2. 若数据库为空，自动从 `jobs.csv` 导入招聘数据
3. 初始化推荐系统与薪资预测模型

浏览器访问 <http://127.0.0.1:5000>

### 默认账号

| 角色 | 用户名 | 密码 |
|------|--------|------|
| 管理员 | admin | 123456 |

普通用户可通过注册页面自行创建。

## 系统架构说明

- **数据层**：SQLite 存储 `User`（用户）、`Job`（岗位）、`Favorite`（收藏）、`Log`（日志）四张表
- **业务层**：`app.py` 内置数据清洗、分类归一化、情感分析等预处理逻辑，以及 TF-IDF 推荐与随机森林预测模型
- **接口层**：50+ 个 RESTful JSON API，覆盖薪资、城市、岗位、企业、对比、建议等分析维度
- **展示层**：Jinja2 模板 + Bootstrap 5 + ECharts 渲染各类图表，支持 PC 端响应式浏览
